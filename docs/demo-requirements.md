# Технические требования к системе онлайн-банкинга «Demo Bank» (демонстрационный документ)

Этот документ создан исключительно для демонстрации работы Requirements Intelligence
Agent на защите хакатона. В него намеренно заложены типичные дефекты требований:
неоднозначность, неполнота, противоречие, дублирование, непроверяемое требование
и одно качественное требование без проблем.

## 1. Функциональные требования

REQ-1: Система должна разрешать пользователю войти в личный кабинет по логину и паролю.
После трёх неверных попыток ввода пароля учётная запись блокируется на 15 минут.

REQ-2: Система должна работать быстро и быть удобной для пользователя.

REQ-3: Время отклика при переводе средств между своими счетами не должно превышать
2 секунд с момента нажатия кнопки «Перевести» до отображения результата.

REQ-4: Время отклика при переводе средств между своими счетами не должно превышать
10 секунд.

REQ-5: Пользователь должен иметь возможность выйти из личного кабинета по кнопке
«Выход» в правом верхнем углу экрана.

REQ-6: Пользователь должен иметь возможность завершить сеанс работы в приложении
в любой момент времени через меню профиля.

REQ-7: Система должна поддерживать push-уведомления о входящих платежах.

## 2. Нефункциональные требования

REQ-8: Система должна быть надёжной.

REQ-9: Система должна обрабатывать не менее 500 одновременных запросов на перевод
средств без деградации времени отклика более чем на 20%.

## 3. Ограничения и роли

REQ-10: Операции на сумму свыше 1 000 000 тенге должны подтверждаться одноразовым
кодом из SMS.

REQ-11: Администратор системы имеет полный доступ ко всем операциям клиентов без
дополнительного подтверждения.
